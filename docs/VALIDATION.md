## A/B/C 比较

50 篇合成文档共享同一份种子。每个版本从独立数据库开始。相同的字符切分、稀疏向量、余弦阈值 0.18、Top-1、Mock 生成器、问题顺序、权限变更步骤保持固定。保留集与开发题分别存放，保留题在配置固定后运行，未依据保留结果调整阈值或改写语料。原始 JSON 保存题集和语料源文件的 SHA-256。

| 版本 | 核心行为 | 安全检查通过 | 开发问答通过 | 保留问答通过 | 保留题服务内 P50 / P95 |
|---|---|---:|---:|---:|---:|
| A 普通 RAG | 在固定合成副本中忽略读 ACL，全库检索，关闭缓存复用 | 7/13 | 6/10 | 8/12 | 6.841 / 9.301 ms |
| B 权限感知 | 检索前过滤，送模前及返回前复核，无答案缓存复用 | 13/13 | 8/10 | 10/12 | 8.613 / 10.809 ms |
| C 权限感知与缓存 | 在 B 上启用按用户、配置、纪元匹配和复核的答案缓存 | 13/13 | 8/10 | 10/12 | 8.434 / 10.849 ms |

三种版本共用版本化文档更新、删除及历史清理机制。B 保留安全的历史和在途请求复核，因此 B 也能正确处理撤权。A 只在实验模块中有实例化路径，隔离库只接受内置合成语料。在线查询 API 的请求参数没有关闭 ACL 的开关。

固定安全回归 S01–S13 把合法访问和越权检查都计入分母。A 失败于 S02、S03、S04、S07、S08、S09，涉及普通员工或管理员取得 HR 文档、研发同部门横向读取、撤权后重新生成、打开旧引用，以及新生成的泄露结果再次出现在历史中。**六项失败不能当成六个独立漏洞。** B/C 的 13/13 仅适用于这组场景。S06 对 B 的预期是同用户再查仍无缓存复用，对 C 的预期是命中缓存且没有再次送模。

HTTP 负向测试另外覆盖伪造身份、替换 ID、缓存数据仍在但权威规则被改动、故障注入和在途请求。生成器探针记录实际收到的片段 ID，与审计的 context、响应的 refs 对照。对于缓存命中，探针应没有新增调用。不同层级的用例有意重叠，表中数字不能加总为独立漏洞数。

| 指标 | 分子 / 分母 | 具体定义 |
|---|---:|---|
| 检索 Hit@1 | 7/9 | 有授权答案的题中，首个返回来源为标注目标的题数 |

| 引用正确且有权读取 | 7/7 | 实际发出的引用中，目标文档正确、标注事实在原文偏移范围内且用户满足种子 ACL 的条数 |

打分使用标注事实短语（英文忽略大小写）、目标文档和独立的种子授权判定。Mock 摘录可直接与来源核对。没有使用 LLM 裁判，也没有独立人工标注者。这套打分无法测量语言流畅度、复杂推理或自由表述的语义等价性。

**原文抽查。** 本次逐条对照了 H01 的「北侧草坪」与 PUB-010，H04 的「seven snapshots」与 RD-002。H07 和 H08 询问同一个奖金归档批次，管理员返回资料不足，HR 返回 HR-014 的 BONUS-38。核对依据是公开语料表和留存的实测响应。

## 耗时口径与未验证项

- 保留集 C 的阶段 P50 分别为检索 2.818 ms、独立授权复核 2.232 ms、Mock 阶段 0.007 ms、最终复核和保存步骤 2.902 ms。保留集中总服务内 P95 为 10.849 ms。这些计时起止于服务函数内部，最终 SQLite 提交、HTTP 传输和前端绘制在计时范围之外。各阶段的分位数不能直接相加。
- 独立 HTTP 客户端对已启动服务发出 10 个顺序请求。包括完整响应传输，P50 为 11.582 ms，最近秩 P95 为 14.791 ms。连接已预热，登录耗时另计。该记录混合 5 次冷答案缓存和 5 次热缓存，只描述本机这次运行。
- 真实 API 适配器通过本地模拟传输的契约测试。本次没有使用供应商密钥、商业推理服务、训练型语义 Embedding 或 GPU 推理。远程模型的可靠性、生成质量、延迟和提示注入鲁棒性尚未验证。
- 本机 SQLite 全量扫描授权向量；合成短文多数只有一个片段。另有跨页、重叠切块及可解析 / 不可解析 PDF 用例。未验证长文档的大规模召回、并发吞吐、恶意 PDF 资源耗尽、OCR、跨租户部署或长期合规性。
- 当前锁定环境的 Starlette TestClient 对 httpx 传输发出一条弃用提示。测试均实际完成。HTTP 安全结果来自本地项目，不能外推成对企业生产环境的安全保证。
